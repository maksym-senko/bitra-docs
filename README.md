# 🗂️ Bitra Archive

</div>

Добро пожаловать в **Bitra Archive** — единый централизованный архив прошивок, рекавери, кастомных ядер и полезных модификаций для смартфона **Realme GT Neo 2 5G (RMX3370 / bitra)**.

Цель этого проекта — сохранить наследие сообщества, обеспечить быстрый и удобный доступ к стабильным релизам, портам и необходимым файлам для прошивки в одном надежном месте.

---

## 🧭 Навигация проекта

<details>
  <summary><b>🚀 Прошивки</b> (Нажмите, чтобы развернуть)</summary>

  * Здесь будут размещаться ссылки на кастомные и стоковые прошивки (например, CherishOS, EvolutionX, VoltageOS и др.).
  * *Сюда можно добавлять подразделы и ссылки на отдельные файлы.*
</details>

<details>
  <summary><b>⚡ Ядра</b> (Нажмите, чтобы развернуть)</summary>

  * Коллекция кастомных ядер для оптимизации производительности и энергопотребления.
</details>

<details>
  <summary><b>🛠️ Рекавери</b> (Нажмите, чтобы развернуть)</summary>

  * Актуальные версии TWRP, OrangeFox и других кастомных рекавери для устройства bitra.
</details>

<details>
  <summary><b>📦 Firmware</b> (Нажмите, чтобы развернуть)</summary>

  * Официальные прошивки модема, вендора и системные компоненты (firmware-бандлы).
</details>

<details>
  <summary><b>📖 Инструкции</b> (Нажмите, чтобы развернуть)</summary>

  * Пошаговые руководства по разблокировке загрузчика, чистой установке прошивок, прошивке через fastboot / рекавери и решению возможных проблем.
</details>
