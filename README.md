# Bitra Archive

</div>

Добро пожаловать в **Bitra Archive** — единый централизованный архив прошивок, рекавери, кастомных ядер и полезных модификаций для смартфона **Realme GT Neo 2 5G (RMX3370 / bitra)**.

Цель этого проекта — сохранить наследие сообщества, обеспечить быстрый и удобный доступ к стабильным релизам, портам и необходимым файлам для прошивки в одном надежном месте.
