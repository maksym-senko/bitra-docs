# Voltage OS v5.6

* **Android:** 16 (QPR2)
* **Статус:** Unofficial
* **Дата билда:** 18.02.2026
* **Мейнтейнер:** @subodhkr36

---

<details>
<summary><b>  Список изменений </b></summary>

<br>

**Система и Безопасность:**
* ​Февральский патч безопасности.
* ​Исправлены проблемы с обработкой одноразовых паролей (OTP).
* ​Исправлен сброс параметров мобильной сети.
* ​Исправлены проблемы с роумингом и переключателем иконки роуминга.
* ​По умолчанию используется ядро Phoenix без Root-прав.

**​Интерфейс и Кастомизация:**
* ​Добавлена возможность переключения между стилями обзора приложений.
* ​Добавлена возможность переключения между стилями кнопок обзора.
* ​Добавлен переключатель для отключения иконки аккумулятора в статус-баре.
* ​Возвращена поддержка кастомных икон-паков для встроенного лаунчера.
* ​Возвращена раздельная регулировка громкости для отдельных приложений.
* ​Возвращен переключатель индикаторов конфиденциальности.
* ​Добавлен режим Nirvana mode.

**​Медиа, Pulse и Визуализация:**
* ​Исправлен редкий вылет функции Pulse.
* ​Исправлена работа Pulse при воспроизведении через динамик.
* ​Исправлено отображение обложек медиафайлов и Pulse на AOD (Always-On Display).

**​Улучшения Quickspace:**
* ​Шкала батареи Bluetooth в Quickspace теперь также отображает процент заряда аккумулятора телефона.
* ​Нажатие на погоду в Quickspace открывает Omnijaws Weather при отсутствии установленного приложения Google.
* ​Общие исправления и оптимизация работы Quickspace.

</details>

<details>
<summary><b> Известные ошибки </b></summary>

<br>

Портретный режим в OnePlus Camera вылетает после нескольких снимков.

</details>

<details>
<summary><b> Требования </b></summary>

<br>

**Firmware:** 
* F.20 для IN региона 
* F.18 для EU региона.

**GApps:**
* Из сервисов Google поддерживаются только [GrapheneOS Sandboxed Google Play](https://github.com/maksym-senko/bitra-docs/blob/main/Guides%2FSandboxed.md).

* Если вы переходите с кастомных портов OxygenOS или ColorOS, обязательна предварительная прошивка последнего стокового Realme UI вашего региона. 

</details>

<details>
<summary><b> Инструкция по установке</b></summary>

<br>

1. Загрузитесь в кастомное рекавери (Recovery).
2. Прошейте нужное Firmware.
3. Прошейте zip-архив с ROM.
4. Выполните форматирование данных (`Format Data` через ввод `yes`).
5. Перезагрузитесь в систему.

</details>
