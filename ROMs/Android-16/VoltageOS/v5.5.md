# Voltage OS v5.5

* **Android:** 16 (QPR2)
* **Статус:** Unofficial
* **Дата билда:** 29.01.2026
* **Мейнтейнер:** @subodhkr36

---

<details>
<summary><b>  Список изменений </b></summary>

<br>

* Январский патч безопасности.
* Стабильная сборка на базе Android 16 QPR2.
* Vanilla-версия (без встроенных сервисов Google / GApps).
* По умолчанию используется ядро Phoenix v3.2 без Root-прав ([доступна версия с Root](https://github.com/maksym-senko/bitra-docs/blob/main/Kernels/phoeniX/v3.2_15.12.2025.md)).

</details>

<details>
<summary><b> Требования </b></summary>

<br>

**Firmware:** 
* F.20 для IN региона 
* F.18 для EU региона.

**GApps:**
* Из сервисов Google поддерживаются только GrapheneOS Sandboxed Google Play.

* Если вы переходите с кастомных портов OxygenOS или ColorOS, обязательна предварительная прошивка последнего стокового Realme UI вашего региона. 

</details>

<details>
<summary><b> Инструкция по установке</b></summary>

<br>

1. Загрузитесь в кастомное рекавери (Recovery).
2. Прошейте нужное Firmware.
3. Прошейте zip-архив с ROM.
4. Выполните форматирование данных (`Format Data` через ввод `yes`).
5. Перезагрузитесь в систему.

</details>
