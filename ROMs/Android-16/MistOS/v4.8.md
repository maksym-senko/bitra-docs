# Project Mist OS v4.8 (Opaline)

* **Android:** 16 (QPR2)
* **Статус:** Unofficial
* **Дата билда:** 02.07.2026
* **Мейнтейнер:** @subodhkr36

---

<details>
<summary><b>  Список изменений </b></summary>

<br>

**Новые функции и Экраны**
* **CanvasAOD:** Представлен новый кастомизируемый Always-On Display.

**Лаунчер и Интерфейс**
* Исправлена интеграция поиска Google Lens в Mistify Launcher.
* Исправлена проблема, при которой нижняя панель в Mistify Launcher становилась невидимой после разблокировки.
* Исправлена интенсивность размытия в PackageInstaller для единого визуального стиля.
* Исправлена обработка гаммы на вертикальном слайдере регулировки яркости.
* Исправлено поведение долгого нажатия для расширения слайдера яркости.
* Исправлено действие смахивания/закрытия уведомлений в шторке быстрых настроек в стиле iOS.

**Обои и Визуальные эффекты**
* Исправлен сбой и отображение Depth Wallpaper при смене ориентации экрана.
* Исправлена совместимость Depth Wallpaper с Pixel Launcher.

**Система и Стабильность**
* Интегрирован патч безопасности за июнь 2026 года.
* Обновлено встроенное ядро до версии [Entropy v1.5](https://github.com/maksym-senko/bitra-docs/blob/main/Kernels%2FEntropy%2Fv1.5_06.06.2026.md).
* Исправлена очистка событий в Dynamic Bar.
* Исправлена работа Sandbox App Lock (защита приложений).
* Исправлена работа Sandbox Vault (приватное хранилище).
* Дополнительные исправления ошибок и общие улучшения производительности.

</details>

<details>
<summary><b> Известные ошибки </b></summary>

<br>

* Портретный режим в OnePlus Camera вылетает после нескольких снимков.
* Розовый оттенок (pink tint) при съемке на селфи-камеру в ночном режиме.

</details>

<details>
<summary><b> Требования </b></summary>

<br>

**Firmware:**
* [F.20](https://sourceforge.net/projects/bitra-archive/files/Firmware/F20/) для IN региона.
* [F.18](https://sourceforge.net/projects/bitra-archive/files/Firmware/F18/) для EU / Global региона.

Если вы переходите с кастомных портов OxygenOS или ColorOS, обязательна предварительная прошивка последнего стокового Realme UI вашего региона.

</details>

<details>
<summary><b> Инструкция по установке</b></summary>

<br>

**Чистая установка (при переходе с другой прошивки):**
1. Загрузитесь в кастомное рекавери (Recovery).
2. Прошейте необходимый Firmware.
3. Прошейте zip-архив с ROM.
4. Выполните форматирование данных (`Format Data` через ввод `yes`).
5. Перезагрузитесь в систему.

**Обновление (Dirty Flash с предыдущей версии MistOS):**
1. Перейдите в Recovery.
2. Прошейте zip-архив с ROM.
3. Очистите Cache (`Wipe Cache`).
4. Перезагрузитесь в систему.

</details>
