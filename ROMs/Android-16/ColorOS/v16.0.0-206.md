# Color OS v16 Beta

* **Android:** 16
* **Статус:** Unofficial Port
* **Дата билда:** 11.11.2025
* **Мейнтейнер:** @SaiChaitanya888

---

<details>
<summary><b>  Список изменений </b></summary>

<br>

**Система и интерфейс:**
* Формат файла прошивки приведен к стоковому виду.
* Сборка выпущена с оригинальным именем модели RMX3370.
* Исправлено отображение состояния аккумулятора.
* Добавлен скрипт защиты от бутлупа.

**Экран блокировки и AOD:**
* Исправлены новые уведомления на AOD.
* Исправлена полноэкранная работа AOD.
* Исправлен музыкальный плеер на AOD.

**Камера:**
* Исправлена работа камеры (теперь можно использовать версии от Android 15 или Android 16).

</details>

<details>
<summary><b> Примечания и требования </b></summary>

<br>

* По умолчанию включена системная переменная anim 1 (необходима для работы новых анимаций сканера отпечатков пальцев и быстрой зарядки SuperVOOC), из-за чего анимации открытия и закрытия приложений могут работать с задержками. Для повышения плавности рекомендуется её отключить.
* Чистая установка (Clean Flash). 
* По умолчанию используется SukiSU (KernelSU-Next).

</details>

<details>
<summary><b> Инструкция по установке</b></summary>

<br>

1. Замените OrangeFox на актуальную версию TWRP Recovery (OrangeFox использовать нельзя).
2. Если переходите с кастомной прошивки (AOSP), прошейте базовый файл [super](https://pixeldrain.com/u/7XzrnbfQ). Если уже находитесь на ColorOS 15/16 или OxygenOS 15/16 — пропустите этот шаг.
3. Прошейте zip-архив с прошивкой через TWRP.
4. Выполните форматирование данных (`Format Data` через ввод `yes`).
5. Перезагрузитесь в систему.

</details>
