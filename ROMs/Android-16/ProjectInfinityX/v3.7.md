# Project Infinity X v3.7

* **Android:** 16 (QPR2)
* **Статус:** Unofficial
* **Дата билда:** 03.02.2026
* **Мейнтейнер:** @SaiChaitanya888

---

<details>
<summary><b>  Список изменений </b></summary>

<br>

* **Основные изменения платформы (v3.7 QPR2):**
  * Полный ребейз исходного кода на базе AOSP Android 16 QPR2.
  * Возвращена функция таймаута Bluetooth (*авторы: Uldiniad, neobuddy89, idoybh*).
  * Возвращена настройка шрифтов часов на экране блокировки (*автор: neobuddy89*).
  * Добавлена возможность скрывать иконку аккумулятора в статус-баре.
  * Возвращено стандартное приложение AOSP Messaging для всех устройств.

* **Интерфейс и Кастомизация (QS / Lockscreen):**
  * Добавлена поддержка виджетов экрана блокировки Android 16 QPR2 и переключатель их отображения (*автор: aswin7469*).
  * Исправлен камуфляж тайлов Quick Settings при включении чистой черной темы / отключении размытия.
  * Добавлены сплошной черный и белый цвета на экране ввода PIN/пароля (keyguard bouncer) при отключенном размытии.
  * Включение мобильных данных из Quick Settings без всплывающего предупреждения (*автор: neobuddy89*).
  * Исправлена работа Ambient Wallpaper (теперь работает не только на AOD, но и на Ambient Display; *автор: neobuddy89*).

* **Исправления лаунчера и системы:**
  * Исправлена проблема, когда иконки/виджеты не помещались в область Quickspace при отключенном At a Glance.
  * Исправлены отступы дока и строк на рабочем столе при отключенной строке поиска.
  * Исправлен переключатель Adaptive Playback.

* **Временно удаленные функции (несовместимость с QPR2):**
  * Подсветка граней экрана (Ambient edge light).
  * Кастомные икон-паки для встроенного лаунчера *(планируются к возврату в ближайших обновлениях)*.


</details>

<details>
<summary><b> Инструкция по установке</b></summary>

<br>

1. Загрузитесь в кастомное рекавери (Recovery).
2. Прошейте необходимый Firmware
3. Прошейте zip-архив с ROM.
4. Выполните форматирование данных (`Format Data` через ввод `yes`).
5. Перезагрузитесь в систему.

</details>
