# Project Infinity X v3.5

* **Android:** 16 (QPR0)
* **Статус:** Unofficial
* **Дата билда:** 12.12.2025
* **Мейнтейнер:** @bijoyv9

---

<details>
<summary><b>  Список изменений </b></summary>

<br>

* Декабрьский патч безопасности.
* По умолчанию используется ядро ZORO K без Root-прав.

</details>

<details>
<summary><b> Известные ошибки </b></summary>

<br>

* Портретный режим в OPlus Camera вылетает после нескольких снимков.

</details>

<details>
<summary><b> Требования </b></summary>

<br>

**Firmware**: 
* F.20 для IN региона 
* F.18 для EU региона.

**Базовая система:**
* Если вы переходите с кастомных портов OxygenOS или ColorOS, обязательна предварительная прошивка последнего стокового Realme UI вашего региона.

</details>

<details>
<summary><b> Инструкция по установке</b></summary>

<br>

1. Загрузитесь в кастомное рекавери (Recovery).
2. Прошейте необходимый Firmware
3. Прошейте zip-архив с ROM.
4. Выполните форматирование данных (`Format Data` через ввод `yes`).
5. Перезагрузитесь в систему.

</details>
