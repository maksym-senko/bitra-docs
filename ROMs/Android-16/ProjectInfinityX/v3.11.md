# Project Infinity X v3.11

* **Android:** 16 (QPR2)
* **Статус:** Unofficial
* **Дата билда:** 06.06.2026
* **Мейнтейнер:** @subodhkr36

---

<details>
<summary><b> Список изменений </b></summary>

<br>

**Система, Безопасность и Производительность**
* Интегрирован патч безопасности за июнь 2026 года.
* Обновлено встроенное ядро до версии [Entropy-V1.5](https://github.com/maksym-senko/bitra-docs/blob/main/Kernels%2FEntropy%2Fv1.5_06.06.2026.md) (исправлены проблемы с подключением DAC / USB OTG, добавлены варианты KSU и SUSFS).
* Переход на встроенную реализацию **TrickyStore** для обхода проверок Play Integrity / SafetyNet.
* Реализована новая система безопасности: **App Sandbox**, приватный сейф файлов и кастомный пароль для защиты приложений вместо устаревшего AppLock.
* Повышена скорость разблокировки подэкранным сканером (UDFPS) и общая отзывчивость системы после разблокировки.
* Исправлена ошибка отсутствия анимации перехода на рабочий стол при разблокировке отпечатком пальца с AOD.
* Добавлена функция быстрой блокировки ориентации экрана при смене его состояния.
* Исправлена работа системных OTA-обновлений.

**Интерфейс, Часы и Экран блокировки**
* Добавлены новые стили часов для экрана блокировки с улучшенным макетом и предпросмотром.
* Возвращена функция **Peek AOD** (кратковременное отображение экрана AOD после выключения).
* Добавлена настройка кастомного текста оператора и выбор его расположения.
* Исправлено отображение малых икон сети и Wi-Fi в различных темах оформления.
* Исправлены свойства шрифта по умолчанию Google Sans Flex (скругление и адаптивные веса).

**Шторка быстрых настроек (QS), Статус-бар и Звук**
* Добавлена поддержка разделения шторки для всех системных стилей QS.
* Возвращена регулировка яркости свайпом по статус-бару (работает также на экране блокировки).
* Повышена плавность прокрутки шторки QS при высокой нагрузке на систему.
* Восстановлен виброотклик при изменении громкости физическими кнопками в расширенной панели громкости, а также привязано время автозакрытия панели к системным настройкам.

**Многозадачность, Лаунчер и Жесты**
* Добавлены кастомные стили меню недавних приложений (OOS, iOS, Scale).
* Добавлено удержание карточки в меню недавних для быстрого запуска в режиме Freeform / Split Screen.
* Переработан режим плавающих окон (Freeform): переведен на управление «таблеткой» (нажатие — назад, свайп снизу вверх — закрыть, сверху вниз — открыть во весь экран).
* Добавлен жест свайпа для создания частичного скриншота.
* Добавлено автоматическое скрытие боковой панели при активном GameSpace.
* Включен эффект вызова ассистента удержанием кнопки питания.
* Исправлено отображение иконок в меню приложений, даже если отключены тематические иконки.
* Исправлена позиция иконки поиска в меню приложений при отключенной строке поиска на рабочем столе.

**Динамическая панель (Dynamic Bar)**
* Переработан всплывающий модуль управления медиаплером в Dynamic Bar.
* Добавлен фиксатор перетаскивания для ползунка воспроизведения и обновлена стилизованная полоса прокрутки Waveform.
* Исправлена иконка перемешивания треков для отдельных музыкальных плееров.

**Сеть и Беспроводные модули**
* Исправлена ошибка отображения крайне низкого уровня сигнала для 5G-соединений.
* Увеличено покрытие и стабильность работы в сетях LTE+.
* Улучшена стабильность и качество соединения по Bluetooth.

</details>

<details>
<summary><b> Инструкция по установке </b></summary>

<br>

**Чистая установка (при переходе с другой прошивки):**
1. Загрузитесь в кастомное рекавери (Recovery).
2. Прошейте необходимый Firmware.
3. Прошейте zip-архив с ROM.
4. Выполните форматирование данных (`Format Data` через ввод `yes`).
5. Перезагрузитесь в систему.

**Обновление (Dirty Flash с предыдущей версии Project Infinity X):**
1. Перейдите в Recovery.
2. Прошейте zip-архив с ROM.
3. Очистите Cache (`Wipe Cache`).
4. Перезагрузитесь в систему.

</details>
