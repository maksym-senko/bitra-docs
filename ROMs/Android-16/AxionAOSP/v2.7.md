# AxionAOSP v2.7 (Proxima)

* **Android:** 16 (QPR2)
* **Статус:** Official
* **Дата билда:** 14.06.2026
* **Мейнтейнер:** @bijoyv9

---

<details>
<summary><b>  Список изменений </b></summary>

<br>

**Производительность и Алгоритмы**
* **PulseEngine:** Интегрирован новый уникальный алгоритм распределения ресурсов системы, максимизирующий плавность интерфейса в фокусе и снижающий энергопотребление на основе анализа действий пользователя.
* **AxBurstEngine v2:** Добавлена полноценная оптимизация для старых архитектур планировщика (stune устройств).
* **AxAnimationEngine:** Полностью переработаны и сглажены анимации открытия и закрытия приложений.

**Интерфейс и Кастомизация**
* Бэкпортирована совершенно новая шторка быстрых настроек (Quick Settings) из будущей Android 17.
* Добавлен глубокий системный эффект размытия (blur) с оптимизированным потреблением оперативной памяти.
* Обновлен UX часов, добавлено свободное перемещение элементов и новые стили циферблатов, перенесенные из ColorOS.
* Добавлена детальная настройка тематических иконок, кастомный размер значков, регулировка прозрачности в меню недавних, выбор поискового провайдера для QSB строки и новый стиль папок.
* Исправлены фантомные нажатия развернутого Dynamic Bar на экране блокировки и оптимизировано отображение обложек альбомов.

**Специфичные исправления для девайса**
* Восстановлена функция регулировки мощности/яркости диода фонарика (Torch Strength).
* Стоковая камера OnePlus пропатчена для корректной работы и взаимодействия с Google Фото.
* Восстановлено OEM-определение быстрой зарядки: на экране блокировки теперь корректно отображается индикация **SuperDart**.
* Значительно расширен список доступных эквалайзеров и профилей **Dolby Atmos**.
* Встроено ядро [Entropy-V1.5](https://github.com/maksym-senko/bitra-docs/blob/main/Kernels%2FEntropy%2Fv1.5_06.06.2026.md).
* Убран серый экран-баг при пробуждении устройства.
* Исправлено отображение системных приложений в меню раздельной регулировки громкости.

</details>

<details>
<summary><b> Требования </b></summary>

<br>

**Firmware:**
* [F.20](https://sourceforge.net/projects/bitra-archive/files/Firmware/F20/) для IN региона.
* [F.18](https://sourceforge.net/projects/bitra-archive/files/Firmware/F18/) для EU / Global региона.

Если вы переходите с кастомных портов OxygenOS или ColorOS, обязательна предварительная прошивка последнего стокового Realme UI вашего региона.

</details>

<details>
<summary><b> Инструкция по установке</b></summary>

<br>

**Чистая установка (при переходе с другой прошивки):**
1. Загрузитесь в кастомное рекавери (Recovery).
2. Прошейте необходимый Firmware (F.20 IN / F.18 EU/Global).
3. Прошейте zip-архив с ROM.
4. Выполните форматирование данных (`Format Data` через ввод `yes`).
5. Перезагрузитесь в систему.

**Обновление (Dirty Flash с предыдущей версии AxionOS):**
1. Перейдите в Recovery.
2. Прошейте zip-архив с ROM.
3. Очистите Cache (`Wipe Cache`).
4. Перезагрузитесь в систему.

</details>
