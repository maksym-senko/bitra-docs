# Evolution X v11.7

* **Android:** 16 (QPR2)
* **Статус:** Unofficial
* **Дата билда:** 30.04.2026
* **Мейнтейнер:** @subodhkr36

---

<details>
<summary><b>  Список изменений </b></summary>

<br>

**Система и Безопасность**
* **PlayIntegrityFix:** Полностью переработана обработка конфигов, добавлен авто-загрузчик и встроенные защиты импорта.
* **TrickyStore:** Переработан выбор приложений, добавлена поддержка индивидуального режима аттестации для каждого приложения.
* Реструктурирован интерфейс настроек спуфинга, уточнены и обновлены текстовые описания функций.
* Глобальный переключатель Tensor заменен на точечный выбор целевых приложений.
* По умолчанию используется ядро Entropy v1.5 без Root-прав ([доступна версия с Root](https://github.com/maksym-senko/bitra-docs/blob/main/Kernels%2FEntropy%2Fv1.5_06.06.2026.md)).

**Интерфейс и Шрифт**
* Системный шрифт по умолчанию заменен на `google-sans-flex`.
* Обновлена работа и настройки энергосберегающих пикселей.
* Чистка и оптимизация кода динамического бара.
* Удален устаревший оверлей навигационного бара Evo.

</details>

<details>
<summary><b> Известные ошибки </b></summary>

<br>

* Портретный режим в OnePlus Camera вылетает после нескольких снимков.
* Розовый оттенок (pink tint) при съемке на селфи-камеру в ночном режиме.

</details>

<details>
<summary><b> Требования </b></summary>

<br>

**Firmware:**
* [F.20](https://sourceforge.net/projects/bitra-archive/files/Firmware/F20/) для IN региона 
* [F.18](https://sourceforge.net/projects/bitra-archive/files/Firmware/F18/) для EU / Global региона.

Если вы переходите с кастомных портов OxygenOS или ColorOS, обязательна предварительная прошивка последнего стокового Realme UI вашего региона.

</details>

<details>
<summary><b> Инструкция по установке</b></summary>

<br>

1. Загрузитесь в кастомное рекавери (Recovery).
2. Прошейте нужное Firmware.
3. Прошейте zip-архив с ROM.
4. Выполните форматирование данных (`Format Data` через ввод `yes`).
5. Перезагрузитесь в систему.

</details>
