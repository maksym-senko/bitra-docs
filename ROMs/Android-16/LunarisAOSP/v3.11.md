# Lunaris AOSP v3.11

* **Android:** 16 (QPR2)
* **Статус:** Unofficial
* **Дата билда:** 05.06.2026
* **Мейнтейнер:** @subodhkr36

---

<details>
<summary><b>  Список изменений </b></summary>

<br>

**Система, Производительность и Безопасность**
* Интегрирован патч безопасности за июнь 2026 года.
* Обновлено ядро до версии **Entropy-V1.5**.
* Переход на реализацию **TrickyStore** для обхода проверок безопасности.
* Расширенные настройки кастомизации Monet.
* В **Idle Manager** добавлена опция срабатывания только при включенном режиме сна.
* Оптимизированы зум обоев, динамическая панель, песочница и блокировка приложений.
* Обновлены библиотеки `jemalloc` и `arm-optimized-routines`.
* Улучшен fallback-цвет для экрана ввода пароля.
* Влиты свежие изменения из LineageOS.

**Интерфейс и Часы**
* Добавлено 25 новых стилей часов с поддержкой отображения погоды и кнопкой просмотра всех стилей.
* Добавлена кастомизация цвета Skydrove для стилей часов.
* Добавлена переопределение цвета часов на экране блокировки по обложке альбома.
* Исправлена ошибка масштабирования часов, выходивших за пределы макета.
* Устранена задержка разблокировки при использовании Depth Clock.

**Экраны блокировки и Уведомления**
* Добавлена кастомизация цвета и прозрачности для виджета информации на экране блокировки.
* Возвращена функция Peek AOD (кратковременное включение Always-On Display).
* Добавлена интеграция размытия для уведомлений и других элементов UI.
* Добавлена центровка для иконок уведомлений в статус-баре.
* Добавлено отображение счетчика уведомлений.

**Шторка быстрых настроек (QS) и Статус-бар**
* Добавлен начальный вариант разделения шторки.
* Реализован вертикальный вариант расширения слайдера яркости.
* Добавлено управление яркостью с помощью свайпа по статус-бару.
* Добавлен тактильный отклик на слайдерах виджетов QS и заменены MSDL-виброотклики на нативные для плиток.
* Исправлено отображение цвета процента батареи при активном тинте статус-бара.

**Лаунчер, Многозадачность и Жесты**
* Улучшена анимация сворачивания приложений на рабочий стол и кастомные анимации недавних приложений.
* Управление окнами Freeform переведено на адаптивную плашку жестов.
* Добавлен жест свайпа вниз для блокировки приложения в меню недавних.
* Добавлен жест свайпа вверх для перехода в режим разделения экрана.
* Добавлена настройка радиуса скругления углов карточек задач в меню недавних.
* Поддержка адаптивных форм иконок из сторонних паков.

</details>

<details>
<summary><b> Известные ошибки </b></summary>

<br>

* Портретный режим в OnePlus Camera вылетает после нескольких снимков.
* Розовый оттенок (pink tint) при съемке на селфи-камеру в ночном режиме.

</details>

<summary><b> Требования </b></summary>

<br>

**Firmware:** 
* [F.20](https://sourceforge.net/projects/bitra-archive/files/Firmware/F20/) для IN региона.
* [F.18](https://sourceforge.net/projects/bitra-archive/files/Firmware/F18/) для EU / Global региона.

Если вы переходите с кастомных портов OxygenOS или ColorOS, обязательна предварительная прошивка последнего стокового Realme UI вашего региона.

</details>

<details>
<summary><b> Инструкция по установке</b></summary>

<br>

**Чистая установка (при переходе с другой прошивки):**
1. Загрузитесь в кастомное рекавери (Recovery).
2. Прошейте необходимый Firmware.
3. Прошейте zip-архив с ROM.
4. Выполните форматирование данных (`Format Data` через ввод `yes`).
5. Перезагрузитесь в систему.

**Обновление (Dirty Flash с предыдущей версии LunarisAOSP):**
1. Перейдите в Recovery.
2. Прошейте zip-архив с ROM.
3. Очистите Cache (`Wipe Cache`).
4. Перезагрузитесь в систему.

</details>
