# Project Sakura v10.0

* **Android:** 16 (QPR0)
* **Статус:** Unofficial
* **Дата билда:** 05.02.2026
* **Мейнтейнер:** @SaiChaitanya888

---

<details>
<summary><b>  Список изменений </b></summary>

<br>

* Первый релиз Project Sakura 10.0 на базе Android 16 (QPR0).
* Построено на исходном коде LineageOS 23.0 с кастомными функциями и UI-улучшениями.
* Поставляется с ядром Linux 4.19.325.
* Доступны версии GApps и Vanilla.

</details>

<details>
<summary><b> Требования </b></summary>

<br>

**Firmware:**
* F.20 для региона India.
* F.18  для EU / Global.

</details>

<details>
<summary><b> Инструкция по установке</b></summary>

<br>

1. Загрузитесь в кастомное рекавери (Recovery).
2. Прошейте Firmware.
3. Прошейте zip-архив с ROM.
4. Выполните форматирование данных (`Format Data` через ввод `yes`).
5. Перезагрузитесь в систему.

</details>
