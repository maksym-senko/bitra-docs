# Pixel OS 14.0 EOL

* **Android:** 14 (QPR3)
* **Статус:** Unofficial
* **Дата билда:** 15.10.2024
* **Мейнтейнер:** @david_bitra

---

<details>
<summary><b>  Список изменений </b></summary>

<br>

**Безопасность и база:**
* Интегрирован октябрьский патч безопасности.
* Выполнена синхронизация с последними исходниками (завелась функция Circle to Search).
* Обновлено ядро до последней версии Bigshot Kernel.

**Системные функции и оптимизации:**
* Добавлены свойства для игр (GamesPropsUtils).
* Интегрированы жесты для сенсорного экрана (TouchScreen Gestures).
* Подписано по умолчанию (Sign by default), благодаря чему банковские приложения работают без получения root-прав.

**Камера и мультимедиа:**
* Добавлена стоковая камера Oplus Camera.
* Интегрирован Dolby Atmos.

</details>

<details>
<summary><b> Инструкция по установке</b></summary>

<br>

1. Загрузитесь в кастомное рекавери (Recovery).
2. Выполните форматирование данных (`Format Data` через ввод `yes`).
3. Прошейте zip-архив с ROM.
4. Перезагрузитесь в систему.

</details>
