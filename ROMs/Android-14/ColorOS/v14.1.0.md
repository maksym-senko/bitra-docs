<details>
<summary><b> Инструкция по установке</b></summary>

<br>

**Инструкция по установке для всех пользователей (All users)**
1. Загрузитесь в кастомное рекавери (Recovery).
2. Прошейте файл `Firmware`.
3. Прошейте `super.img`.
4. Сделайте Wipe (`Dalvik/Cache`).
5. Выполните форматирование данных (`Format Data` через ввод `yes`).
6. Перезагрузите устройство обратно в рекавери и выполните `Format data` еще раз.
7. Перезагрузитесь в систему.

</details>
