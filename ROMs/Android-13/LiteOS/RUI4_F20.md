# Lite OS RUI4 F.20 

* **Android:** 13
* **Статус:** Stok Mod IN
* **Дата билда:** 12.09.2024
* **Мейнтейнер:** @SUNIL_SARRAF

---

<details>
<summary><b>  Список изменений </b></summary>

<br>

**Безопасность:**
* Вшит июльский патч безопасности.

**Оптимизация и системный софт:**
* Полностью удалены все трекеры и встроенный системный мусор.
* Достигнута повышенная плавность интерфейса (Smooth UI).

**Дополнительно:**
* Прошивка идет со встроенными root-правами из коробки (используйте Kitsune Mask / Magisk).

</details>

<details>
<summary><b> Инструкция по установке </b></summary>

<br>

**Инструкция для пользователей из Индии (IN users):**
1. Распакуйте загруженный архир с прошивкой.
2. Прошейте firmware.
3. Прошейте системный раздел (`flash super`).
4. Выполните форматирование данных (Format Data), набрав yes.
5. Перезагрузка в систему.

**Инструкция для пользователей из Европы (EU users):**
1. Распакуйте загруженный архир с прошивкой.
2. Выполните подмену свойств через командную строку/терминал в рекавери:
  * `resetprop ro.commonsoft.ota RE879AL1`
  * `resetprop ro.separate.soft 2169A`
3. Прошейте firmware.
4. Прошейте системный раздел (`flash super`).
5. Выполните форматирование данных (Format Data), набрав yes.
6. Перезагрузка в систему.


</details>
