# Pixel OS 13.0

* **Android:** 13
* **Статус:** Official
* **Дата билда:** 16.02.2023
* **Мейнтейнер:** @cristianvaz

---

<details>
<summary><b>  Список изменений </b></summary>

<br>

**Ядро:**
* Обновлено кастомное ядро BigShot kernel.

**Дисплей и плавность:**
* Добавлена поддержка LiveDisplay 2.1.
* Добавлены переключатели в шторку (QS Tiles) для функций устранения мерцания (Anti-flicker / DC Dimming) и режима высокой яркости на солнце (Sunlight enhancement).
* Изменена реализация Smooth Display для управления частотой обновления экрана.

**Связь и сеть:**
* Обновлены модули WCNSS и WPA Supplicant из стока RUI4_F02.

**Аудио и подсистема:**
* Использована реализация QCOM для аудиоэффектов.
* Префикс dsp. удален из профилей питания аудио и видео.

**Система и оптимизация:**
* Корректно распределено распределение прерываний (IRQ affinity).
* Включена проверка датчика приближения для жестов на выключенном экране.
* Включена передача обратного давления (backpressure propagation) в SurfaceFlinger.
* Исправлены устаревшие (deprecated) элементы профилей питания.

</details>

<details>
<summary><b> Требования </b></summary>

<br>

* Firmware RUI4_F02.

</details>

<details>
<summary><b> Инструкция по установке</b></summary>

<br>

1. Загрузитесь в кастомное рекавери (Recovery).
2. Выполните форматирование данных (`Format Data` через ввод `yes`).
3. Прошейте zip-архив с ROM.
4. Выполните `Wipe Dalvik / ART Cache`.
5. Перезагрузитесь в систему.

</details>
