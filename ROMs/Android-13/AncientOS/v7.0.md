# AncientOS v7.0 TexasCake

* **Android:** 13
* **Статус:** Official
* **Дата билда:** 02.03.2023
* **Мейнтейнер:** @SathamHussainM

---

<details>
<summary><b>  Список изменений </b></summary>

<br>

* Синхронизация с последней версией исходного кода AncientOS.
* Первая официальная сборка.
* Сборка с принудительным режимом.
* Прохождение CTS (Compatibility Test Suite) по умолчанию.
* Импорт CarrierConfig из RMX3370_11.C.11.
* Включение VoLTE, VoWifi/WFC по умолчанию и поддержка 5G SA для Jio.
 

</details>

<details>
<summary><b> Инструкция по установке</b></summary>

1. Загрузитесь в кастомное рекавери (Recovery).
2. Выполните форматирование данных (`Format Data` через ввод `yes`).
3. Прошейте zip-архив с ROM.
4. Выполните `Wipe Dalvik / ART Cache`.
5. Перезагрузитесь в систему (`Reboot to System`).

</details>
